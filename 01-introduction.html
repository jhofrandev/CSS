¿Qué es exactamente CSS?

Si HTML se esncarga de definir la estructura del documento e indicarle al navegador que es cada cosa (encabezados, enlaces, imágenes, etc), CSS se encarga de indicarle al navegador como "dibujar" cada uno de esos elementos.

HTML: Navegador esto es un cuadrado

CSS: Navegador a este cuadrado dibujale el borde gris y el fondo azul

Con CSS puedes controlar:

  • Colores y Tipografías: Cambiar el tono del texto, fondos y fuentes.
  • Diseño (Layout): Decidir dónde va cada caja, crear columnas o rejillas complejas.
  • Adaptabilidad (Responsive Design): Hacer que tu sitio se vea perfectamente tanto en un monitor de 30 pulgada como en un celular pequeño.
  • Efectos: Añadir sombras, bordes redondeados, transiciones y animaciones.

La regla de Oro: La Sintaxis

Escribir CSS es como dar instrucciones directas. Cada "regla" se compone de tres partes principales:

  1. Selector: Indica a qué elemento le vas a aplicar el estilo (ej: un párrafo <p>).
  2. Propiedad: Qué quieres cambiar (ej: el color)
  3. Valor: El nuevo ajuste (ej: azul)
Selector {Propiedad: Valor}

Ejemplo real:

      
        h1 {
          color: #2ecc71;
          font-size: 32px;
          text-align: center;
        }

¿Por qué se llama "en Cascada" (Cascading)?

"Cascada" significa que el orden importa:

  • Jerarquía: Si tienes dos reglas que chocan, heneralmente la que está escrita ,ás abajo (al final del archivo) gana.
  • Herencia: Algunos estilos que le das a un elemento padre (como el cuerpo de la página) los heredan automáticamente sus hijos (como los párrafos), a menos que indiques lo contrario.
  • Especificidad: Hay selectores que tienen más "fuerza" que otros (por ejemplo, un ID le gana a una clase).
