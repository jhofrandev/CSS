Conectando estilos con HTML

Existen 3 maneras de incluir CSS en un documento HTML, casa una tiene un propósito y un "momento de gloria" diferente.

1. Inline CSS (Estilos en línea)

Es la forma mas directa, pero también la menos recomendada para proyectos grandes. El estilo se escribe directamente dentro de la etiqueta HTML usando el atributo style.

  • Cómo se ve: <p style="color:red; font-size: 18px;">Este es un texto rojo.</p>

  • Cuándo usarlo: Para pruebas rápidas o cuando necesitas aplicar un estilo único a un solo elemento que no se repetirá jamás.

  • Desventaja: Mezcla el contenido con el diseño, lo que hace que el código sea difícil de mantener y leer.

2. Internal CSS (CSS Interno)

Aquí los estilos se agrupan en una sección dedicada dentro del mismo archivo HTML. Se utiliza la etiqueta <style> dentro del <head>.

  • Cómo se ve:

              
            <head>
              <style>
                body {
                  background-color: white;
                }
              </style>
            </head>

  • Cuándo usarlo: Cuando trabajas en una sola página (como una "landing Page" sencilla) y no quieres crear archivos adicionales.

  • Desventaja: Si tu sitio tiene 10 páginas y quieres cambiar el color de los párrafos, tendrías que editar los 10 archivos uno por uno.

3. External CSS (CSS Externo)

Esta es la forma profesional y la más organizada. Creas un archivo independiente con extensión .css y lo vinculas a tu HTML mediante una etiqueta <link>.

  • Cómo se ve en el HTML:
    •         
          <head>
            <link  rel="stylesheet" href="./styles/main.css" >
          </head>
  • Cómo se ve el archivo styles.css:
    •         
            p {
              color: white;
              font-weight: bold;
            }
  • Ventaja principal: Puedes controlar el diseño de TODO un sitio web (cientos de páginas) modificando un solo archivo CSS. Es la base de la eficiencia en el diseño web.
