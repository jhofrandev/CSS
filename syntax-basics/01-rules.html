Qué es una regla CSS

Entender la estructura de una regla de CSS es como aprender la gramática de un nuevo idioma; una vez conoces la sintaxism puedes darle cualquier instrucción al navegador.

1. La Anatomia de una Regla CSS

Escribir CSS consiste en crear "reglas". Una regla completa es el conjunto de instrucciones que aplicas a un elemento específico.

La estructura básica se ve así:

      Selector{propiedad:valor;}

A. El Selector

Es el "quién" de la regla. Indica al navegador a qué elemento del HTML debe aplicarle el estilo.

  • Ejemplo: p (selecciona todos los párrafos), h1 (selecciona los títulos principales) o .mi-clase (selecciona elementos con esa clase específica).

B. El Bloque de Declaración

Es todo lo que se encuentra entre las Llaves { }. Dentro de este bloque puedes poner tantas declaraciones como necesites, siempre separadas por un punto y coma (;).

C. La Declaración

Es la instrucción específica que combina una propiedad y un valor.

  • propiedad: Es el atributo que quieres cambiar (el "que"), como el color, el tamaño de letra o el margen.
  • Valor: Es el ajuste específico que eliges (el "cómo"), como blue, 16px o center.

2. Ejemplo Práctico

Imagina que queremos que todos los subtitulos ( h2 ) sean de color rojo y estén centrados. La regla se vería así: 

      
        h2 { 
          color:red; 
          text-align:center; 
        }
  • h2: El selector, indica que aplicaremos esto a todas las etiquetas <h2>.
  • color: La propiedad que queremos cambiar (el color del texto).
  • red: El valor que le asignamos (el color rojo).
  • text-align: Otra propiedad (la alineación del texto).
  • center: Su valor correspondiente (centrado).

3. La Importancia del Punto y Coma ";" y las "{}"

  • Las Llaves { }: Delimitan el inicio y el fi de los estilos para ese selector específico.
  • Los Dos Puntos: Separan la propiedad del valor para que el navegador sepa dónde termina el nombre del atributo.
  • El Punto y Coma: Es crucial. Le indica al navegador que esa declaración ha terminado y que puede pasar a la siguiente, Si lo olvidas, el navegador se confundirá y probablemente ignorará todo el bloque de estilos.
