Comentarios en CSS

Los comentarios son esa herramienta "invisible" pero vital que te permite hablar contigo mismo (o con otros desarrolladores) dentro del código sin que el navegador se entere.

¿Qué es un comentario en CSS?

Un comentario es una nota en tu archivo de estilos que el navegador ignora por completo al renderizar la página. Su función es puramente informativa para los humanos que leen el código,

La Sintaxis

A diferencia de HTML (que usa <!---->) o javascript (que usa //), CSS utiliza una sintaxis única basada en barras y asteriscos:

  • Apertura: /*
  • Cierre: */

Ejemplo básico:

      
        /* Esto es un comentario de una sola línea */
        /* O también puedes escribirlo en 
        varias líneas sin problema */
        h1 { 
          color:blue; /* Puedes poner comentarios al final de una línea */
        }

¿Para qué se utilizan?

Los comentarios son fundamentales para mantener el orden, especialmente cuando tus archivos empienzan a crecer:

  • Organizar Secciones: Puedes dividir tu archivo CSS en bloques lógicos (ej: Encabezado, Navegación, Pie de página).

  • Explicar "Porqués": A veces usas un truco extraño o un valor muy específico para corregir un error. Un comentario explica por qué hiciste eso para que no borres por error en el futuro.

  • Desactivar Código (Debugging): Si una regla está rompiendp tu diseño, puedes "comentarla" para desactivarla temporalmente, sin tenet que borrarla.

Ejemplo de organización:

      
        /* =========================================
           HEADER
           ========================================= */
        .header {
          background-color: #333;
        }

        /* =========================================
           NAVIGATION
           ========================================= */
        .nav {
          margin-top: 20px;
        }

        /* Temporalmente desactivado para pruebas:
        .nav-link {
          color: green;
        } 
        */
